# Claude Code Multi-Agent Orchestration — Deep Dive

An interactive slide deck covering Claude Code's multi-agent system: subagents, teams, prompt engineering, permissions, debugging patterns, and production best practices.

**[View the presentation](https://nguyentran4896.github.io/claude-agents-presentation/)**

## What's Inside

- **Concepts** — Mental models, subagent lifecycle, built-in vs custom agents
- **Prompt Engineering** — Crafting effective agent prompts with frontmatter and tools
- **Permissions & Security** — Permission matrix, auto-allow, plan mode
- **Teams** — Multi-agent coordination, task delegation, worktrees
- **CLAUDE.md Mastery** — Configuration tips, progressive disclosure, anti-patterns
- **Debugging & Gotchas** — Common pitfalls and how to avoid them
- **Scaling Patterns** — Real-world patterns for production agent workflows

## Usage

Open `index.html` in a browser or visit the [GitHub Pages link](https://nguyentran4896.github.io/claude-agents-presentation/). Navigate with arrow keys or the sidebar.
